## Установка

1. Создать новый Supabase project.

2. Открыть:

Supabase → SQL Editor

3. Полностью вставить:

supabase/schema.sql

4. Выполнить SQL.

5. В Supabase открыть:

Authentication → Providers → Email

6. Включить Email provider.

7. Для первой тестовой версии можно отключить Confirm email.

8. Создать файл:

config.js

9. Скопировать в него содержимое:

config.example.js

10. Получить значения:

Supabase → Project Settings → API

и вставить:

window.APP_CONFIG = {
  SUPABASE_URL: "...",
  SUPABASE_ANON_KEY: "..."
};

11. Загрузить проект в GitHub.

12. Подключить репозиторий к Vercel.

13. Deploy.

## Безопасность

Все финансовые записи содержат user_id.

RLS включён на всех пользовательских таблицах.

Любой SELECT/INSERT/UPDATE/DELETE разрешён только для записей,
принадлежащих текущему auth.uid().

Supabase service_role key никогда не должен попадать в браузер,
GitHub или Vercel frontend.

В браузере используется только anon/publishable key.

YYYY-MM

Например:

2026-08

## Важное ограничение текущей версии

Баланс на главной странице сейчас считается по операциям
выбранного месяца.

Для полноценного исторического баланса в следующей версии
нужно добавить отдельный запрос всех операций пользователя
или таблицу счетов/кошельков.
